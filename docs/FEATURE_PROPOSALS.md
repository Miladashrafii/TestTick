# TestTick — proposed modern features

These are **not implemented yet**. Approve any you want added.

## High impact (recommended)

1. **AI-assisted test case drafting**  
   Generate steps/expected results from a short prompt or requirement text; human edits before save.

2. **CI / automation sync**  
   Ingest results from Playwright/Cypress/Jest/JUnit XML via webhook or CLI; map to automated cases.

3. **Live dashboards & flaky detection**  
   Trend pass-rate over builds, highlight flaky cases, and surface “regressions since last green build”.

4. **Issue tracker deep-link**  
   One-click create/link Jira, Linear, GitHub Issues from a failed execution (OAuth + templates).

5. **Review / approval workflow**  
   Draft → In review → Approved for cases and plans (like modern TMS / docs tools).

## Collaboration

6. **@mentions & activity feed** on cases, executions, and requirements.  
7. **Real-time co-presence** (“Sara is executing this case”).  
8. **Shared filters & saved views** per team.

## Quality & scale

9. **Risk-based / exploratory sessions** with time-boxed charters and session notes.  
10. **Data-driven cases** (parameter tables / datasets).  
11. **Import/export** Excel + TestLink XML for migration.  
12. **REST + GraphQL public API** with API keys (TestLink XML-RPC successor).

## UX polish

13. **Keyboard-first execution** (j/k navigate, p/f/b status).  
14. **Dark mode toggle** (opt-in, not default).  
15. **Custom fields UI** end-to-end (schema already supports fields).

Reply with numbers you want (e.g. `1, 2, 11, 13`) and we’ll implement those next.
